# Faithful Gatherings

A responsive website for Faithful Gatherings wedding planning, event planning, and décor services. Built with plain HTML, CSS, and JavaScript; no installation or build step is required.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then **Save**.
4. GitHub will display the published URL after deployment: https://secopsengineer.github.io/faithful-gatherings/

A custom domain is optional and can be connected later through Pages settings.

## Before the business launch

- Confirm the business email, phone number, service area, and social links.
- Connect an actual inquiry delivery service and replace the preview notice. The current form only prepares a message to copy; it does not submit or store inquiries.
- Confirm rights to reuse the photographs migrated from the existing Wix site. They are illustrative imagery, not a claim that these are events planned by this business.
- Add verified portfolio images and testimonials when available.

## Editing

- `index.html`: page content and sections.
- `styles.css`: colors, typography, responsive layouts.
- `site.js`: mobile navigation and inquiry preparation.
- `assets/`: photographs reused from the existing public Wix website.

The site uses relative asset paths so it works at a GitHub Pages project URL. Fonts load from Google Fonts, with local serif and sans-serif fallbacks. Form contents stay in the visitor's browser unless they choose to copy them.

## Content and design

Home → Services → Our heart → The experience → Inquiry builder.

Warm ivory, deep olive, editorial serif typography, an arched lead photograph, and a responsive mobile layout. Business content is based on https://mesquitebaseballof.wixsite.com/faithful-beginnings . No testimonials, credentials, prices, or contact details have been invented.
