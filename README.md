# Faithful Gatherings

A responsive website for Faithful Gatherings wedding planning, event planning, and décor services. Built with plain HTML, CSS, and JavaScript; no installation or build step is required.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then **Save**.
4. GitHub will display the published URL after deployment: https://secopsengineer.github.io/faithful-gatherings/

A custom domain is optional and can be connected later through Pages settings.

## Editing

- `index.html`: page content and sections.
- `styles.css` and `bold.css`: colors, typography, responsive layouts.
- `site.js`: mobile navigation and service selection.
- `assets/`: photographs reused from the existing public Wix website.

The site uses relative asset paths so it works at a GitHub Pages project URL. Fonts load from Google Fonts, with local serif and sans-serif fallbacks. Inquiry submissions are sent to FormSubmit and emailed to the business after recipient activation. The form retains the default spam check and includes a honeypot.
